# Постоянные сессии на insight-game.ldprvpered.workers.dev

Сайт может оставаться на существующем адресе Workers. Публикуется Worker со статическими файлами из `dist/` и базой D1. Вкладку не нужно держать открытой: состояние записывается в базу, а код приложения выполняется при запросах. Отдельный постоянно работающий компьютер не нужен.

В этой версии:

- «Сохранить как новую сессию» сохраняет снимок всех игроков под отдельным названием и подключает автосохранение этой игры.
- «Сохранённые игры» показывает последние 100 сессий с датой и количеством участников. «Продолжить» загружает сессию; данные другой игры остаются в базе.
- В подключённой сессии ходы и заметки отправляются автоматически после короткой паузы. «Сохранить сейчас» позволяет явно дождаться записи. Перед закрытием проверьте надпись «сохранено».
- На том же браузере обычный адрес сайта восстанавливает последнюю подключённую игру. Для другого устройства откройте список или постоянную ссылку комнаты.
- При потере связи остаётся локальная копия с признаком несохранённых изменений. После восстановления связи приложение повторяет запись. На другом устройстве доступна последняя версия, уже дошедшая до базы.
- В базе D1 не задан срок удаления сессий. Перезапуск браузера и обычный повторный деплой Worker не удаляют их. Хранилище остаётся, пока вы сами не удалите базу/записи и пока аккаунт Cloudflare обслуживается.
- Доступ и список сессий общие для этого публичного сайта. Одновременно редактировать одну сессию лучше с одного устройства: при двух редакторах последнее сохранение заменяет предыдущее.

## Настройка один раз через Cloudflare и терминал

Используйте Node.js 22 или новее. В каталоге репозитория:

```powershell
cd C:\Users\Admin\.gemini\antigravity\scratch\insight-game
npm ci
npx wrangler login
```

1. В Cloudflare откройте **Storage & databases → D1 SQL Database → Create database**. Имя: `insight-game-sessions`. Выберите бесплатный план, если предлагается выбор. Откройте созданную базу и скопируйте **Database ID**.
2. Запишите этот ID в конфигурацию и создайте таблицу:

```powershell
npm run configure:db -- ВАШ_DATABASE_ID
npm run db:remote
```

`configure:db` заменяет нулевой ID в `wrangler.worker.jsonc`; без настоящего ID деплой не готов. В конфигурации имя привязки — **DB**, имя базы — **insight-game-sessions**.

3. Опубликуйте сервер и страницу вместе:

```powershell
npm run deploy
```

Имя Worker — `insight-game`. Выполняйте команду в том аккаунте, которому принадлежит `ldprvpered.workers.dev`. Ожидаемый адрес после деплоя: **https://insight-game.ldprvpered.workers.dev/**. Команда публикует и Worker, и готовый `dist/index.html`; отдельная загрузка файлов сайта не требуется.

4. Проверьте **https://insight-game.ldprvpered.workers.dev/api/health**. Ответ должен быть:

```json
{"ok":true,"storage":"D1"}
```

Если `DB_NOT_BOUND` — база не привязана. Если `DB_NOT_INITIALIZED` — не применена миграция. HTML или пустой 404 вместо JSON означают, что загружена одна статика без нового Worker.

5. Откройте игру → **Облако & Синхронизация** → введите название → **Сохранить как новую сессию**. Сделайте пробный ход/заметку, дождитесь «сохранено», закройте страницу и снова откройте. Для проверки с другого устройства воспользуйтесь списком сохранённых игр.

## Автоматический деплой из GitHub

В существующем Worker **insight-game → Settings → Builds** подключите `4nba/insight-game`, ветку `main` и корень репозитория.

- Build command: `npm ci`
- Deploy command: `npm run db:remote && npm run deploy`
- Конфигурация Worker: `wrangler.worker.jsonc` (команды npm уже передают этот путь).

Предварительно впишите настоящий Database ID и сохраните конфигурацию в GitHub. Миграция создаёт таблицу через `IF NOT EXISTS` и не удаляет сохранённые игры. Для обычных правок исходников сначала запустите `python bundle.py` и закоммитьте пересобранные `index.html` и `dist/index.html` — Cloudflare публикует готовый файл без зависимости от Python в сборочной среде.

Не используйте deploy command вида `wrangler deploy --assets ...` без серверного файла. Для этой версии нужен `npm run deploy`, который публикует и API, и файлы. Прежний `wrangler.jsonc` относится к старому варианту Pages + KV и здесь не используется.

## Если таблицу удобнее создать в панели

В D1 → созданная база → Console выполните содержимое `migrations/0001_sessions.sql`. Для привязки в панели: Worker **insight-game → Bindings → Add binding → D1 database**, Variable name **DB**, база **insight-game-sessions**. Привязка в `wrangler.worker.jsonc` должна указывать на ту же базу при последующих деплоях.

## Запасная копия

Кнопка «Скачать .json» сохраняет все данные текущей игры отдельно. «Загрузить .json» открывает файл локально и отключает прежнюю комнату. Затем нажмите «Сохранить как новую сессию», чтобы записать импортированную игру в D1 отдельно от старой.

Cloudflare устанавливает лимиты бесплатного тарифа; приложение не обещает бессрочную бесплатность или отсутствие квот. Для небольшой игры одного ведущего частота записей мала. Проверяйте актуальные условия в документации:

- https://developers.cloudflare.com/workers/static-assets/
- https://developers.cloudflare.com/d1/get-started/
- https://developers.cloudflare.com/d1/platform/pricing/
