# Психотерапевтическая игра самопознания «Инсайт» (Александра Свобода)
## Цифровой интерактивный пульт Ведущего игры

**Cloudflare Workers + постоянные сессии D1:** актуальная настройка для `insight-game.ldprvpered.workers.dev` описана в [CLOUDFLARE.md](CLOUDFLARE.md). Новый вариант работает на Workers со статикой и базой; переносить сайт в Pages не требуется. Разделы ниже про Pages + KV относятся к прежнему варианту.

Веб-приложение для проведения и фасилитации трансформационной психологической игры **«Инсайт»**. Рассчитано на ведущего: помогает вести группу, фиксировать броски, показывать методические карточки, считать ресурсы, отслеживать траекторию и блоки.

> Это инструмент ведущего, а не замена терапии. Спорные методические места (особенно трактовка клеток 99–104) стоит сверить с автором игры.

---

## Что реализовано

### Группа до 20 участников

Сверху постоянно виден обзор группы: номер, имя, клетка и статус каждого участника. Нажмите на участника, чтобы открыть его ход. Номер на фишке соответствует номеру в обзоре и списке игроков; одинаковые имена больше не мешают различать участников. Доступны 20 цветов.

В окне «Игроки» можно добавлять участников по одному или раскрыть «Добавить список участников» и вставить имена, каждое с новой строки. Добавление списка отменяется одним действием. Начальный «Игрок 1» уже занимает одно место: его имя можно изменить кнопкой «Имя» в списке игроков. Очередь идёт по порядку списка, начиная с первого родившегося; завершившие игру пропускаются.

Это общий пульт ведущего на одном устройстве. Участникам не требуется входить на сайт. Для переноса всей группы используйте JSON или ссылку-снимок. На GitHub Pages данные игроков сохраняются в браузере, а не в репозитории.

### Поле и правила

- **104 клетки** в точной «змейке» физического поля: 8 рядов по 13 клеток, старт на **98 «Инсайт»**, рождение на **1**, финиш — точное попадание на **98**.
- **6 уровней** с цветами поля:
  - 🔴 1. Тело (1–13)
  - 🟠 2. Отношения и Деньги (14–39)
  - 🟡 3. Части Я / ЭГО (40–52)
  - 🟢 4. Чувства и Социум (53–78)
  - 🔵 5. Самореализация / Работа (79–91)
  - 🔷 6. Интеллект и Мышление (92–104)
- **Лотосы-центры**: 7, 20, 33, 46, 59, 72, 85, 98.
- **Фаза рождения**: все ставят фишки на 98 и кидают, пока не выпадет 1. Приложение ведёт очередь: после неудачного броска ход переходит к следующему ещё не рождённому игроку; первым в игру входит тот, кто родился раньше.
- **Правило трёх посещений**: на третьем попадании на клетку срабатывает предупреждение о блоке и запись в карту игрока.
- **Символы клеток**:
  - ❤️ — ресурс уровня: игрок называет номер из списка ресурсов своего цвета, приложение показывает слово и добавляет ресурс;
  - 🃏 — карта из колоды: игрок называет номер, ведущий открывает карту по номеру;
  - ❌ — потеря ресурса уровня;
  - 🧭 — карта-вектор 4 уровня;
  - ➔N — обязательный переход на клетку N;
  - 🛑 101 — выход из игры;
  - 🪷 98 — финиш.
- **Ресурсы делятся на базовые и заработанные**. При потере сначала списывается заработанный ресурс, базовый — в последнюю очередь. В интерфейсе показывается `всего (база+заработано)`.
- **Клетки 99–104** — «ловушки ума» после финиша: если бросок проносит мимо 98, игрок может попасть в них; с 104 стрелка возвращает на 43. Это трактовка по полю и карточкам, её стоит подтвердить у автора методики.

### Колоды

В приложение перенесены 6 тематических колод из методических материалов (238 карт). **Каждая карта пронумерована — игрок называет номер, ведущий открывает карту по номеру.**

- «Вторичные выгоды» — 32 карты;
- «Страх» — 48 карт;
- «Зависимости» — 34 карты;
- «Деньги» — 36 карт;
- «Убеждения» — 33 карты;
- «Одиночество» — 49 карт;
- «МАК (примеры)» — 6 демонстрационных метафорических карт.

Плюс **6 колод ресурсов по уровням** (слова из «Ресурсы цвета по номерам»): красная 18, оранжевая 30, жёлтая 19, зелёная 15, голубая 21, синяя 19. На клетке с сердцем игрок называет номер ресурса — приложение показывает слово и предлагает сразу добавить ресурс. Номера сохранены в порядке исходного документа; повторяющиеся слова в источнике оставлены как отдельные номера.

Названия карт взяты из методических документов; текст-подсказка для ведущего («как это связано с запросом») добавлен приложением, а не является дословной авторской формулировкой.

### Автоматизация и надёжность

- **Отмена действий**: кнопка `↶` или `Ctrl+Z` отменяет последний ход, списание, переход или изменение колоды (до 40 шагов).
- **Автоматическое применение крестов** можно отключить галочкой «символы» — тогда ведущий списывает ресурс вручную.
- **Финиш и выход**: попадание на 98 фиксирует завершение запроса; 101 — выход из игры. Игрока можно вернуть в игру кнопкой в баннере (для 101 — с новым рождением).
- **Карты по номеру без повторов**: после взятия номер убирается из колоды; если игрок называет уже взятый номер, приложение показывает карту повторно и предупреждает. Колода перемешивается заново после опустошения.
- **Карта-вектор**: если физической карты нет под рукой, приложение открывает выбор клетки назначения с подсказками по 4 уровню.
- **Резервный сценарий для неизвестной колоды**: если в данных клетки указана колода, которой нет в приложении (например, после импорта своей версии поля), показывается подсказка взять физическую карту и вопросы клетки.
- **Карта игрока**: ФИО, дата рождения, запрос, ресурсы по уровням, блоки и страхи/убеждения по каждому уровню, инсайты, траектория. Всё это печатается в PDF/на бумаге.
- **Ссылка-снимок** сжимается через `CompressionStream` (для 3 игроков — около 1 КБ вместо 6 КБ). Есть резервный обычный формат для старых браузеров.
- **Облачная комната** (Cloudflare KV): при открытии ссылки `?room=...` приложение сначала читает комнату и не перезаписывает её локальной пустой игрой. Запись в облако debounce-ится, чтобы не отправлять запрос на каждую букву. Если облачный API недоступен (например, сайт открыт на GitHub Pages), бейдж честно показывает **«офлайн»**, а игра продолжает сохраняться локально.
- **Локальное сохранение** в `localStorage`, экспорт/импорт `.json`, восстановление из кода сессии.

### Как передавать игру между ПК и ведущими

| Сценарий | Что использовать | Как это работает |
|---|---|---|
| Один компьютер, одна вкладка | `localStorage` | Состояние сохраняется автоматически при каждом действии |
| Передать смену другому ПК | «Скопировать ссылку сессии» | Сжатый снимок всей игры в ссылке; второй ведущий открывает и продолжает |
| Многодневная игра / архив | `.json` | Полный файл состояния; загружается обратно в приложении |
| Два ведущих одновременно | Облачная комната Cloudflare | Опрос каждые 4 секунды; изменения летят в KV |

Важно:

- **GitHub Pages — только статика.** Функции `/api/room/...` там не работают, поэтому облачная комната на GitHub Pages будет показывать «офлайн». Для смены ПК используйте ссылку сессии или `.json` — этого достаточно.
- **Cloudflare Workers + D1** — текущий вариант: сервер `worker.js`, конфигурация `wrangler.worker.jsonc`, привязка `DB`, именованные сессии и список сохранённых игр. Инструкции в `CLOUDFLARE.md`.
- **Cloudflare Pages + Git + KV** — прежний вариант комнаты, с привязкой `INSIGHT_KV` и функциями из `functions/`. Его нельзя запустить одной загрузкой статических файлов.
- **Одновременное редактирование** использует стратегию last-write-wins: кто последним сохранил, тот и прав. Для очереди ведущих это нормально, но двум людям не стоит менять одно и то же состояние в одну секунду.
- **Лимиты Cloudflare Free**: около 100 000 запросов функций и 100 000 чтений KV в сутки, 1 000 записей KV в сутки. Для игры этого с запасом, но это не «бесконечный» тариф.

### Интерфейс

- Светлая тёплая панель ведущего, пастельные цвета уровней, мягкие тени и цветовые акценты.
- **Номерные колоды и ресурсы**: игрок называет номер — ведущий нажимает цифру и открывает карту/ресурс; есть и случайный выбор.
- **Полноэкранное поле** (`⛶ Во весь экран`, выход по `Esc`) — удобно для проектора или второго монитора.
- Названия клеток в две строки, чтобы длинные подписи вроде «Потребность в восхищении» не обрезались в одну.
- Адаптивная вёрстка: на телефоне панель управления уходит под поле, поле прокручивается горизонтально.
- Модальные окна закрываются по `Esc` и клику по фону.
- Динамические данные экранируются при вставке в HTML (имена игроков, заметки, импортированные сессии).

## Запуск

Самый простой способ — открыть **`index.html`** двойным кликом. Файл полностью автономен: Tailwind, стили, данные и логика уже встроены. Интернет не нужен.

Готовый файл для публикации лежит и в `dist/index.html`.

## Сборка

`index.html` — **сгенерированный** файл. Не редактируйте его вручную: изменения затрутся при следующей сборке.

Исходники:

- `index.src.html` — HTML-шаблон;
- `style.css` — собственные стили;
- `gameData.js` — 104 клетки, 6 уровней, тематические колоды и колоды ресурсов;
- `app.js` — игровая логика и состояние;
- `ui.js` — интерфейс ведущего;
- `tailwind.input.css` + `tailwind.config.js` — исходник для Tailwind;
- `tailwind.css` — собранный Tailwind (коммитится, чтобы сборка не требовала интернета).

Пересобрать CSS после изменения классов:

```powershell
npx --yes tailwindcss@3.4.17 -c tailwind.config.js -i tailwind.input.css -o tailwind.css --minify
```

Пересобрать автономный `index.html` и `dist/index.html`:

```powershell
python bundle.py
```

## Бесплатный деплой

### Cloudflare Pages (облачная комната)

Это прежняя схема. Для текущего адреса Workers используйте [CLOUDFLARE.md](CLOUDFLARE.md).

Облачная комната работает только в проекте **Pages**, подключённом к Git. При ручной загрузке `Upload assets` Cloudflare не собирает папку `functions/`.

1. Запушьте репозиторий на GitHub.
2. В Cloudflare: **Workers & Pages → Create application → Pages → Connect to Git**.
3. Выберите репозиторий. Build command оставьте пустой, output directory — `.` (в репозитории уже лежит `index.html` и папка `functions/`).
4. Создайте KV namespace: **Storage & Databases → KV → Create a namespace**, имя `INSIGHT_KV`.
5. В настройках Pages-проекта: **Settings → Bindings → Add binding → KV namespace**, variable name `INSIGHT_KV`, выбрать созданный namespace.
6. Если задаёте привязку в `wrangler.jsonc`, раскомментируйте `kv_namespaces`, впишите реальный ID namespace и передеплойте.
7. Проверка: откройте `https://<проект>.pages.dev`, подключите комнату, бейдж должен стать зелёным. Если бейдж янтарный «офлайн» — API не собран или KV не привязан.

Если видите ошибку **«Bindings cannot be added to a Worker that only has static assets»**, опубликуйте сервер `worker.js` вместе со статикой командой `npm run deploy`, как описано в `CLOUDFLARE.md`. Если используете прежние Pages и видите **«Pages functions are not supported»** при `Upload assets`, используйте Git-интеграцию Pages.

### GitHub Pages
1. Загрузите `index.html` в публичный репозиторий.
2. **Settings → Pages → Branch: main**.
3. Сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

На GitHub Pages облачной комнаты нет: бейдж покажет «офлайн», но локальное сохранение, ссылка сессии и `.json` работают полностью.

### Telegram Mini App
1. Разместите сайт на Cloudflare Pages или GitHub Pages.
2. В `@BotFather` выполните `/newapp`, выберите бота и вставьте ссылку.

### Автономно
Скачайте `index.html` на компьютер или телефон и открывайте в браузере без интернета.

## Ограничения и важные оговорки

- **Колоды**: в приложении 6 тематических колод и 6 колод ресурсов. Если вы используете другую редакцию комплекта, сверьте названия карт с физическими колодами; текст-подсказки в приложении — интерпретация для ведущего. Для клеток без отдельной колоды в методичке выбрана ближайшая по теме (например, «Безопасность» → «Страх», «Денежные блоки» → «Деньги»); ведущий может заменить колоду вручную.
- **Название облачной комнаты — это фактически ключ доступа.** Отдельной авторизации нет: кто знает имя комнаты, может читать и писать её состояние. Не используйте для чувствительных данных и выбирайте трудно угадываемое имя.
- **Ссылка-снимок** использует `CompressionStream`. В старых браузерах без него применяется длинный резервный формат; для Telegram надёжнее облачная комната или `.json`.
- **Трактовка 98/99–104** — рабочая гипотеза по полю и карточкам. Если автор методики говорит иначе, логику финиша нужно поправить.
- Приложение не заменяет супервизию, терапию и методическое обучение ведущего.
