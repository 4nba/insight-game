# Психотерапевтическая игра самопознания «Инсайт» (Александра Свобода)
## Цифровой интерактивный пульт Ведущего игры

Интерактивное веб-приложение для проведения и фасилитации трансформационной психологической игры **«Инсайт»**. 
Разработано специально для ведущего: позволяет вести группу участников, фиксировать их броски кубика, автоматически выводить психологические карточки с вопросами, управлять ресурсами, отслеживать траекторию и блоки.

---

### 🌟 Ключевые возможности

1. **Полное соответствие физическому полю**:
   - Все 104 клетки поля (8 рядов по 13 колонок) расположены в точном порядке траектории движения («змейка»).
   - 6 уровней / сфер жизни с аутентичной цветовой гаммой:
     - 🔴 1. **Тело** (1–13): базовые эмоции (страх, злость, радость), психосоматика, границы.
     - 🟠 2. **Отношения и Деньги** (14–39): партнерство, сексуальность, денежные блоки, баланс «брать-давать».
     - 🟡 3. **Части Я / ЭГО** (40–52): внутренний Критик, Самозванец, Воин, Жертва, Контролер, достоинство.
     - 🟢 4. **Чувства и Социум** (53–78): обида, вина, прощение, открытость, невротические «Зовы» (власти, свободы, любви).
     - 🔵 5. **Самореализация и Работа** (79–91): проявленность, творчество, способности, преодоление страха публичности.
     - 🔷 6. **Интеллект и Мышление** (92–104): ментальные вирусы, ограничивающие установки, гибкость ума, Инсайт.
   - Центры уровней — клетки-Лотосы (7, 20, 33, 46, 59, 72, 85, 98).

2. **Автоматический вывод карточек**:
   - При перемещении фишки или клике на клетку мгновенно отображается полная методическая карточка.
   - Терапевтический контекст и глубинный смысл клетки.
   - Точечные вопросы ведущего для глубокого исследования запроса.
   - Быстрые кнопки в 1 клик:
     - `+ Ресурс игроку` / `- Списать ресурс`
     - `🚀 Совершить переход по стрелке на клетку [X]` (автоматическое перемещение по всем стрелкам поля)
     - `🃏 Вытянуть карту из колоды`

3. **Соблюдение всех правил игры**:
   - **Фаза Рождения (клетка 98 ➔ 1)**: подсказка и контроль ожидания единицы на кубике.
   - **Выдача 6 базовых ресурсов**: по 1 на каждый уровень в начале игры.
   - **Правило 3 посещений (Блок)**: система автоматически ведет учет количества попаданий на каждую клетку. При 3-м попадании срабатывает звуковое и визуальное предупреждение о психологическом блоке!
   - **Клетка 101 «Одержимость»**: предупреждение о выходе из игры и сверхконтроле.

4. **Карта игрока (Dossier)**:
   - Личная карточка участника (ФИО, дата рождения, запрос на игру, заметки по блокам, инсайты).
   - Счетчики ресурсов по всем 6 уровням.
   - История траектории ходов (`98 ➔ 1 ➔ 7 ➔ 13...`).
   - Кнопка **«Скопировать для Telegram»**: генерирует структурированный и красивый текст для отправки игроку в личные сообщения или в общий чат.
   - Кнопка **«Печать / Экспорт в PDF»**: готовый бланк для печати или сохранения.

5. **Встроенные колоды карт и МАК**:
   - Колода «Вторичные выгоды»
   - Колода «Страхи»
   - Колода «Убеждения»
   - Колода «Отношения и Зависимость»
   - Универсальная колода МАК (Метафорические ассоциативные карты)

6. **Надежность и независимость**:
   - Приложение на 100% автономно: файл `index.html` содержит все стили, данные и логику.
   - Все изменения автоматически сохраняются в `localStorage` браузера — при обновлении страницы или случайном закрытии вкладки игра не потеряется.
   - Экспорт в `.json` файл и импорт из файла для переноса игры на другой компьютер.

### 🚀 Варианты бесплатного деплоя (доступно из РФ без VPN)

#### Вариант 1: Cloudflare Pages (Самый простой и быстрый)
- **Адрес:** `https://ваш-проект.pages.dev`
- **Плюсы:** Работает в РФ молниеносно, бесплатный SSL, не блокируется, можно загрузить прямо через браузер без установки Git.
- **Инструкция:**
  1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com/).
  2. Перейдите в раздел **Workers & Pages** ➔ **Create application** ➔ вкладка **Pages**.
  3. Выберите **Upload assets** (Загрузить файлы вручную).
  4. Перетащите папку с файлом `index.html` и нажмите **Deploy site**.
  5. Готово! Вы получите красивую постоянную ссылку.

#### Вариант 2: GitHub Pages (Классика для разработчиков)
- **Адрес:** `https://ваш-логин.github.io/insight-game/`
- **Плюсы:** 100% бесплатно навсегда, надежно, не блокируется РКН.
- **Инструкция:**
  1. Создайте публичный репозиторий на GitHub (например, `insight-game`).
  2. Загрузите туда файл `index.html`.
  3. Перейдите в **Settings** ➔ **Pages** ➔ в пункте **Branch** выберите `main` (или `master`) и нажмите **Save**.
  4. Через 1-2 минуты сайт откроется по ссылке `https://<ваш-логин>.github.io/insight-game/`.

#### Вариант 3: Telegram Mini App (Внутри Telegram)
- **Плюсы:** Ведущий и участники могут открывать игру прямо в мессенджере Telegram с телефона или компьютера без перехода в браузер.
- **Инструкция:**
  1. Разместите сайт на Cloudflare Pages или GitHub Pages (варианты 1 или 2).
  2. Откройте в Telegram официального бота `@BotFather`.
  3. Отправьте команду `/newapp`, выберите своего бота, укажите название и вставьте полученную ссылку на сайт.
  4. Теперь игра открывается прямо внутри Telegram!

#### Вариант 4: Автономный запуск (Zero-Hosting)
- Файл `index.html` можно просто скачать на компьютер или телефон и открывать двойным кликом в любом браузере (Chrome, Edge, Safari, Яндекс.Браузер) даже без подключения к интернету.

### 📁 Структура проекта
- `index.html` — Полностью собранное автономное веб-приложение (Single Page App).
- `gameData.js` — База данных 104 клеток, 6 сфер и 5 колод карт.
- `app.js` — Ядро игровой механики и управление состоянием.
- `ui.js` — Интерактивный интерфейс ведущего.
- `style.css` — Стилизация игрового поля и модальных окон.
- `bundle.py` — Скрипт сборки в единый файл.
